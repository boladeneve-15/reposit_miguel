TEMA: HARDWARE

COMO FUNCIONA?

Este sistema é um CRUD desenvolvido em JavaScript para cadastrar e gerenciar informações sobre hardware.

CREATE

Permite cadastrar um novo hardware informando: nome, marca, tipo e modelo. Cada cadastro recebe automaticamente um ID.

READ

Permite consultar os dados cadastrados. O READ (ID) procura um hardware específico pelo seu ID, enquanto o READ (ALL) mostra todos os hardwares cadastrados.

UPDATE

Permite alterar as informações de um hardware existente. O ID permanece o mesmo e somente nome, marca, tipo e modelo podem ser modificados.

DELETE

Remove um hardware da lista através do seu ID. O ID excluído não é reutilizado em novos cadastros.

REGRA DOS IDs

Os IDs são sequenciais e nunca são reutilizados. Por exemplo: se existirem os IDs 1, 2, 3, 4 e o ID 3 for excluído, o próximo cadastro receberá o ID 5.
